# 🔐 Password Strength Checker

A simple C program that analyzes a password and determines its strength based on different security criteria.

## 📌 Features

- Checks password length
- Detects uppercase letters
- Detects lowercase letters
- Detects numbers
- Detects special characters
- Gives an overall strength rating

## 📊 Strength Levels

| Score | Strength |
|-------|----------|
| 0–2   | Weak     |
| 3–4   | Medium   |
| 5     | Strong   |

## 🛠️ Technologies Used

- C Programming
- Standard C Libraries
  - `stdio.h`
  - `string.h`
  - `ctype.h`

## ▶️ How It Works

The program checks whether the password contains:

1. At least 8 characters
2. Uppercase letters
3. Lowercase letters
4. Numbers
5. Special characters

The more criteria the password meets, the stronger it is rated.

## 🎯 Purpose

This project was created to practice C programming and learn basic cybersecurity concepts related to password security.

## ⚠️ Disclaimer

This is an educational project. It checks basic password characteristics and is not a complete real-world password security system.
